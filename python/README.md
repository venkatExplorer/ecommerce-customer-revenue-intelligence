# Python EDA & Data Analysis

This folder contains Python-based exploratory data analysis and data validation performed for the E-Commerce Customer & Revenue Intelligence Platform.

## Tools

- Python
- Pandas
- NumPy
- Matplotlib

## Analysis Performed

- Data loading and inspection
- Data type validation
- Missing value checks
- Duplicate checks
- Sales analysis
- Monthly sales trend analysis
- Category-level analysis
- State-level analysis
- Customer segment analysis
- Order and customer metrics
- Business insight generation

## Dataset Used

The Python analysis uses the prepared e-commerce analytical dataset generated during the project workflow.

The analysis focuses on:

- Sales
- Orders
- Customers
- Sellers
- Quantity
- Average Order Value
- Product categories
- Customer segments
- States

## Output

The analysis helps identify:

- Overall sales performance
- Monthly revenue trends
- Category performance
- Geographic sales distribution
- Customer segment contribution
- Order and customer patterns
