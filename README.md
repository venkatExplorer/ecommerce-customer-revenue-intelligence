# E-Commerce Customer & Revenue Intelligence Platform

An end-to-end data analytics project that transforms e-commerce data into business-ready insights using Python, BigQuery, dbt, SQL, and Tableau.

## Project Overview

This project analyzes customer behavior, sales performance, product performance, operational metrics, and marketing data to support data-driven business decisions.

## Technology Stack

- Python & Pandas
- SQL
- Google BigQuery
- dbt
- Tableau Public
- Git & GitHub

## Data Pipeline

Python / Pandas
↓
BigQuery
↓
dbt Staging Models
↓
dbt Fact Models
↓
dbt Business Marts
↓
Tableau Public

## Key Analysis Areas

- Sales performance
- Customer analytics
- Product performance
- Operational performance
- Marketing performance
- Business KPIs
- Trend analysis

## Dashboard

The project includes Tableau dashboards covering:

- Monthly Sales Trend
- Sales by Category
- Sales by State
- Sales by Customer Segment
- Total Sales
- Total Orders
- Total Customers
- Average Order Value
