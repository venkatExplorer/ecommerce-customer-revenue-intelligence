# Processed Data

This folder represents the cleaned datasets generated by the Python data cleaning and validation pipeline.

The processed datasets include:

- customers_clean.csv
- products_clean.csv
- sellers_clean.csv
- orders_clean.csv
- order_items_clean.csv
- payments_clean.csv
- deliveries_clean.csv
- returns_clean.csv
- marketing_campaigns_clean.csv
- customer_sessions_clean.csv

## Processing

The datasets were cleaned and validated using Python and Pandas.

The pipeline performs:

- Duplicate detection
- Date conversion
- Missing-value checks
- Invalid-value checks
- Referential integrity validation
- Business-rule validation
- Derived field creation
- Export of cleaned datasets

The processed datasets were subsequently loaded into Google BigQuery for SQL analysis and dbt transformations.
